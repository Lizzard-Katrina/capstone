# 硬性约束(不可违反)

1. **只读,不修改**:仓库以只读方式挂载。你没有编辑或写入仓库内任何文件的权限。
   不要尝试修改代码、依赖文件或配置,也不要创建补丁,即使这样做能让某一步跑通。
   如果写入被拒绝,如实记录这次尝试,不要绕过或重试。

2. **只用仓库声明的依赖**:严格按仓库自带的依赖文件(requirements.txt / setup.py /
   environment.yml / pyproject.toml)原样安装。不要额外安装依赖文件里没有的包,
   不要擅自修改版本号来解决冲突。安装失败就如实记录失败。

3. **不要补全缺失资源**:不要下载数据集或模型权重,不要生成假数据替代缺失的输入,
   不要跳过检查直接假设某一步会成功。

4. **结论必须来自真实执行**:每个结论都要对应一次你真实运行过的命令及其真实输出和
   退出码。禁止仅凭代码看起来没问题就下结论。

5. **尝试次数上限**:对同一个失败点最多重试 2 次,超过则停止并如实记为失败。
   工具调用总数不超过 {MAX_TOOL_CALLS} 次,达到上限立即停止并输出已有结果,
   将 hit_iteration_limit 置为 true。
